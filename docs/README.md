# docs

One directory per target repository, named after the repo's directory
(`~/source/acme-api` → `docs/acme-api/`).

These are written and maintained by sessions, per `playbooks/doc-sync/PLAYBOOK.md`.
They are spine's long-term memory: read them at session start, update them at session
end. `docs/_template/` is the starting shape for a repo seen for the first time.
